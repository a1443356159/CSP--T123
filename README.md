一份可独立阅读的中文学习讲义，包含知识讲解、完整教学例题、输入输出、样例推演、解答、复杂度分析、关键代码和章末练习答案。链接仅用于补充训练，学习正文不需要打开外部题面。

## 三个学习篇章

### 第一篇：第一题——基础实现

1. 备考方法与程序基本功：C 风格输入输出、数组边界、统计。
2. 基础枚举与小模拟：网格更新、矩形相交、日期处理。

### 第二篇：第二题——STL 与常用算法

3. **STL 独立专章**：头文件与迭代器、sort、unique、二分与离散化、vector、string、pair、stack、queue、priority_queue、set、multiset、map，以及复杂度、失效规则、容器选择和带答案练习。
4. 前缀和与差分。
5. 二分与双指针。
6. 贪心与基础数学。
7. 搜索与剪枝。
8. 动态规划入门。
9. 基础背包与计数。

### 第三篇：第三题——字符串解析与综合模拟

10. 字符串处理与解析基础。
11. 综合模拟：路径规范化、授权管理、表达式解析、树形查询、模板展开。
12. 综合训练与复盘：差值数对、二维差分、非抢占任务调度。

题号划分用于组织学习路线，不表示每次考试的题型固定。STL 放在第二篇，同时为第三篇的复杂状态管理服务。书末附录补充多重背包、混合背包、多维费用、方案恢复、计数撤销、LIS 优化、实数搜索、可删堆与 KMP。

## 代码风格与阅读

- 以 `scanf/printf`、普通数组、传统下标循环、结构体和独立函数为主。
- 使用 STL 时写明容器、迭代器类型，不使用 `auto`、Lambda 或结构化绑定；STL 仍然需要 **C++17 编译器**。
- 采用标准头文件；普通数组容量按讲义题目范围预留。
- PDF 中代码带**语法高亮**、行号和浅色背景：蓝色关键字、红棕色字符串、绿色注释、紫色常用函数。
- PDF 代码行号保留显示，并通过空的 `ActualText` 排除在复制文本之外（需阅读器支持此 PDF 标记）；代码正文仍可选择、复制。若阅读器忽略该标记，可直接复制 `code/` 中对应的源程序。
- 输入输出样例使用**浅色边框、输入输出分区和等宽字体**，保留空格与换行，多组样例分别编号。

## 编译讲义

主文件已内嵌全部正文和代码，**只下载 `main.tex` 也可以编译**。使用 XeLaTeX，安装 `ctex`、`fontspec`、`geometry`、`amsmath`、`booktabs`、`longtable`、`enumitem`、`listings`、`fancyvrb`、`needspace`、`tcolorbox`、`accsupp`、`hyperref` 等常用宏包。字体优先 Fandol；Windows 缺少 Fandol 时回退到宋体、黑体。

```sh
mkdir -p dist
xelatex -interaction=nonstopmode -halt-on-error -output-directory=dist main.tex
xelatex -interaction=nonstopmode -halt-on-error -output-directory=dist main.tex
```

PowerShell 创建输出目录：

```powershell
New-Item -ItemType Directory -Force dist | Out-Null
```

## 编辑与代码验证

编辑 `chapters/*.tex` 和 `code/*.cpp` 后，先重新合成主文件，再编译。合成过程不依赖第三方 Python 包。

```sh
python scripts/build.py
python tests/check_examples.py
```

检查脚本需要 Python 3.9+ 和可执行 C++17 的 GNU g++。它编译全部 34 个参考程序，运行 76 组样例与边界检查，并对多个算法执行 525 组固定随机种子的小规模对照测试，共 601 项。测试细节见 [验证说明](tests/README.md)。

`main.tex` 是合成结果，应修改分章或程序源文件后重新生成，以免下次合成覆盖手工修改。正文中较短的讲解片段保留在分章文件里。
