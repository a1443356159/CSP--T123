# 参考程序验证

运行 `python tests/check_examples.py`，需要 Python 3.9+ 和支持 C++17 的 GNU g++。

脚本编译 `code/` 中全部 **68** 个完整程序，使用 `-O2 -Wall -Wextra -pedantic`，共完成 **1793** 项检查：

- **148** 项原题样例和固定边界输入。包含空结果、负数、重复值、端点、零容量、非法表达式、路径越过根、未定义模板、循环依赖、字符串上限，以及大规模稀疏向量、非零段、垦田和机器人宿管的大整数取整。
- **1645** 项小规模随机对照：原 34 个教学程序有 525 项；新增 29 个真题程序分别运行 30 项，共 870 项；五个团队专项完整程序分别运行50项，共250项。
- 固定种子为 `20261009`、`20261011`、`20261012`，结果可复现。比较保留前导、尾随空格，只忽略行尾换行。

原教学算法使用枚举子集、直接求和、直接扫描窗口、直接扫描调度队列等方法作为参考。新增真题的对照包括按单位时段求区间交集、逐格求邻域均值、枚举全部喂食划分、逐步巡查梦境、逐层枚举马步、逐单位格计算田地面积、枚举包邮购物子集、逐阈值扫描非零段等；实现见 `csp_cases.py`。大型边界另检查数组容量、64 位求和和无乘法溢出的比例取整。

原题样例从 `data/csp-practice.json` 读取，与正文保持一致。样例、边界和随机对照不能代替正确性证明，也不代表已在线提交通过或全面性能评估。

编译产物和报告写入被 Git 忽略的 `build/tests/`。正文短片段未全部独立编译；完整参考程序由构建脚本嵌入正文，避免两份实现不一致。

团队专项的独立对照见 `team_cases.py`：枚举全部连续区间、枚举三种钻石分配、枚举全部子矩形，以及直接用任意精度整数求矩形和后模2^64。多组输入检查前缀边界重置；随机数据包含K=0、重复作者、无满足条件的黑格矩形和无符号回绕。
