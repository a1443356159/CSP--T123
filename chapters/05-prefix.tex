\subsection{前缀和}
\subsubsection{一维前缀和}
前缀和$S_i$是数组前i项的和。数组a使用1下标，令$S_0=0$，则
\[
S_i=S_{i-1}+a_i,\qquad \sum_{i=l}^{r}a_i=S_r-S_{l-1}.
\]
右式减去左端点之前的部分，只留下闭区间$[l,r]$。例如$a=[3,-2,7]$，$S=[0,3,1,8]$，第2到3项的和为$8-3=5$。
% snippet:prefix1d
\begin{lstlisting}
s[0] = 0;
for (int i = 1; i <= n; i++) s[i] = s[i-1] + a[i];
long long range_sum(int l, int r) {
    return s[r] - s[l-1];
}
\end{lstlisting}
a、s均至少有$n+1$格，s使用long long。预处理$O(n)$，每次查询$O(1)$，空间$O(n)$；适用于数组不变的多次区间查询。

\subsubsection{二维前缀和}
$S_{i,j}$表示左上角$(1,1)$到$(i,j)$的元素和。上方与左方前缀相加时，左上区域重复一次，需要减去：
\[
S_{i,j}=S_{i-1,j}+S_{i,j-1}-S_{i-1,j-1}+a_{i,j}.
\]
闭矩形$[x_1,x_2]\times[y_1,y_2]$的和为
\[
S_{x_2,y_2}-S_{x_1-1,y_2}-S_{x_2,y_1-1}+S_{x_1-1,y_1-1}.
\]
% snippet:prefix2d
\begin{lstlisting}
// a, s: global arrays; row 0 and column 0 of s are zero.
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
        s[i][j] = s[i-1][j] + s[i][j-1]
                - s[i-1][j-1] + a[i][j];
long long rectangle_sum(int x1, int y1, int x2, int y2) {
    return s[x2][y2] - s[x1-1][y2]
         - s[x2][y1-1] + s[x1-1][y1-1];
}
\end{lstlisting}
第0行、第0列提供空前缀，使贴边矩形也能使用同一公式。预处理$O(nm)$，查询$O(1)$，空间$O(nm)$。
\subsection{差分}
\subsubsection{一维差分}
差分记录相邻项的变化：$d_i=a_i-a_{i-1}$，其中$a_0=0$。前缀累加d可以恢复a。给闭区间$[l,r]$加v，只需在l开始增加v，在$r+1$取消这次增加。
% snippet:difference1d
\begin{lstlisting}
for (int i = 1; i <= n; i++) d[i] = a[i] - a[i-1];
d[n+1] = 0;
void add_range(int l, int r, long long v) {
    d[l] += v;
    d[r+1] -= v;
}
// After all updates:
long long current = 0;
for (int i = 1; i <= n; i++) {
    current += d[i];
    a[i] = current;
}
\end{lstlisting}
a、d使用long long，$a_0=0$，d至少开$n+2$格。例如$[3,-2,7]$给$[2,3]$加4后为$[3,2,11]$。每次修改$O(1)$，q次修改后统一恢复，总时间$O(n+q)$，空间$O(n)$；修改过程中若要查询真实值，需要另计恢复成本。

\subsubsection{二维差分}
给一个矩形加v，在左上角开始生效，在右侧和下侧取消，并在右下方补回被取消两次的部分。
% snippet:difference2d
\begin{lstlisting}
// d: global long long array, initially zero.
void add_rectangle(int x1, int y1, int x2, int y2,
                   long long v) {
    d[x1][y1] += v;
    d[x2+1][y1] -= v;
    d[x1][y2+1] -= v;
    d[x2+1][y2+1] += v;
}
// After all updates, d[i][j] becomes the accumulated increment.
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
        d[i][j] += d[i-1][j] + d[i][j-1] - d[i-1][j-1];
\end{lstlisting}
矩阵用1下标，d至少有$(n+2)\times(m+2)$格，第0行、第0列为0。若原矩阵不是全0，恢复后将增量加到原值上。q次修改与恢复共$O(q+nm)$时间、$O(nm)$空间。
