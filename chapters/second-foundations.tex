\section{基础算法与STL使用}
\subsection{先选算法，再选工具}
数据结构负责保存和查询状态，算法负责说明为什么这样处理正确。不要只根据题名猜容器：已有排序的两组数据可以双指针扫描，不一定需要map；静态区间和优先用前缀和，不必上复杂树结构。普通数组、结构体和独立函数仍是本篇实现的主体。

\subsection{C风格程序中怎样使用STL}
STL是C++标准库的一部分，可以与scanf/printf、普通数组和结构体一起使用。按C++17编译，写清需要的头文件。数组排序可直接使用\texttt{std::sort(a,a+n)}；不需要把已有数组先复制成vector。比较函数写成独立函数；迭代器写明类型。本篇用到的接口会在第二节逐个说明。
\begin{lstlisting}
#include <cstdio>
#include <algorithm>
struct Student { int id, score; };
bool less_by_score(const Student &a, const Student &b) {
    if (a.score != b.score) return a.score > b.score;
    return a.id < b.id;
}
// After declaring array students:
// std::sort(students, students+n, less_by_score);
\end{lstlisting}
以上是比较函数片段，Student必须先定义，例如\texttt{struct Student\{int id,score;\};}。同分时的比较规则来自题面；不能把\texttt{<=}写进严格比较函数。
