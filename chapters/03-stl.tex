\section{STL}
STL是C++标准库中的容器与算法。算法头文件为\texttt{<algorithm>}，容器头文件通常与名称相同，例如\texttt{<vector>}、\texttt{<map>}；priority\_queue使用\texttt{<queue>}，pair使用\texttt{<utility>}。以下接口使用std前缀，按C++17编译。

\subsection{区间与迭代器}
STL算法通常处理左闭右开区间$[first,last)$，包含first、不包含last。普通数组的指针和容器的迭代器都可表示区间端点。
\begin{lstlisting}
int a[] = {4, 1, 3, 2};
std::sort(a, a+4);       // All four elements.
std::sort(a+1, a+3);     // Only a[1], a[2].
std::vector<int> v(4, 0);
for (std::vector<int>::iterator it = v.begin();
     it != v.end(); ++it) {
    *it = 1;
}
\end{lstlisting}
begin()指向第一个元素，end()指向末元素后面，不能解引用。空容器满足begin()==end()。指针和vector迭代器支持常数时间的加减、下标与相减；set、map迭代器只能逐个前进或后退，不能加一个整数。遍历n个元素为$O(n)$。

\subsection{sort：排序}
sort按升序排列一个区间，要求随机访问迭代器；普通数组和vector可以使用。比较函数返回“a是否应排在b前面”，必须使用严格顺序，相等对象不能互相排在前面。
% snippet:stl_sort
\begin{lstlisting}
bool greater_int(int a, int b) { return a > b; }
struct Student { int score, id; };
bool by_score(const Student &a, const Student &b) {
    if (a.score != b.score) return a.score > b.score;
    return a.id < b.id;
}
// int a[n]; Student students[n]; arrays already contain data.
std::sort(a, a+n);                 // Ascending.
std::sort(a, a+n, greater_int);    // Descending.
std::sort(students, students+n, by_score);
\end{lstlisting}
最后一种排序先按成绩降序，再按编号升序。比较器不能写成大于等于；sort不保证等价对象保留原顺序。n个元素需要$O(n\log n)$次比较，若单次比较不是常数时间，还要计入比较成本。

\subsection{unique：去相邻重复}
unique把相邻重复段压成一个元素，返回新的逻辑末尾，不改变容器实际大小。若要去除所有重复值，先排序，让相同值相邻。
% snippet:stl_unique
\begin{lstlisting}
int a[] = {3, 1, 3, 2, 2};
std::sort(a, a+5);
int len = (int)(std::unique(a, a+5) - a);
// Only a[0..len-1] is the distinct result: 1, 2, 3.
std::vector<int> v = {3, 1, 3, 2, 2};
std::sort(v.begin(), v.end());
v.erase(std::unique(v.begin(), v.end()), v.end());
\end{lstlisting}
数组只使用新的len；vector再用erase删除无效尾段。unique本身$O(n)$，排序后去重总时间$O(n\log n)$。新末尾之后的值不能作为去重结果使用。

\subsection{lower\_bound：第一个不小于}
对非降区间，lower\_bound返回第一个大于等于x的位置，全部小于x时返回末尾。
% snippet:stl_lower
\begin{lstlisting}
int a[] = {2, 2, 5, 7};
int x = 3;
int p = (int)(std::lower_bound(a, a+4, x) - a);
bool exists = p < 4 && a[p] == x;
// Here p == 2, exists == false.
\end{lstlisting}
返回值是位置，不一定指向x；先判断是否到达末尾。普通数组和vector上为$O(\log n)$时间。
\subsection{upper\_bound：第一个严格大于}
upper\_bound返回第一个大于x的位置。配合lower\_bound，可以得到x的全部出现位置$[l,r)$。
% snippet:stl_upper
\begin{lstlisting}
int a[] = {2, 2, 5, 7};
int x = 2;
int l = (int)(std::lower_bound(a, a+4, x) - a);
int r = (int)(std::upper_bound(a, a+4, x) - a);
int count = r-l; // Here [l,r) == [0,2), count == 2.
\end{lstlisting}
普通数组和vector上两次查询共$O(\log n)$。对set、map应调用容器自身的lower\_bound、upper\_bound；通用算法在这些迭代器上可能进行线性次数的移动。

\subsubsection{离散化}
离散化把较大的值映射为有序编号，保留相等关系和大小关系。复制原数组、排序去重，再查每个原值的位置。
% snippet:discretize
\begin{lstlisting}
// a[0..n-1] is unchanged; b and rank each have at least n slots.
for (int i = 0; i < n; i++) b[i] = a[i];
std::sort(b, b+n);
int size = (int)(std::unique(b, b+n) - b);
for (int i = 0; i < n; i++)
    rank[i] = (int)(std::lower_bound(b, b+size, a[i]) - b);
\end{lstlisting}
例如$[100,7,100]$变为编号$[1,0,1]$。编号之差不等于原值之差，不能直接用于距离计算。时间$O(n\log n)$，空间$O(n)$。

\subsection{vector：可变长数组}
vector连续存储元素，支持下标访问和末尾增删。size()是实际元素数，capacity()是已分配容量；reserve只预留容量，resize改变元素数。
% snippet:stl_vector
\begin{lstlisting}
std::vector<int> v;
v.reserve(10);          // size=0; no element may be indexed.
v.push_back(4); v.push_back(7);
v.resize(4, 0);         // v = [4,7,0,0].
v[1] = 9;
v.pop_back();           // v = [4,9,0].
v.insert(v.begin()+1, 5); // v = [4,5,9,0].
v.erase(v.begin()+2);   // v = [4,5,0].
v.assign(3, 2);         // Replace all elements: [2,2,2].
\end{lstlisting}
下标访问、size、empty、back为$O(1)$；push\_back均摊$O(1)$，发生扩容的一次为$O(n)$；pop\_back为$O(1)$。中间插入、删除需要移动后续元素，为$O(n)$；初始化、assign和resize新增k个元素至少处理这k项。pop\_back、back要求非空，下标必须小于size。

扩容会使原迭代器、指针和引用失效；未扩容的插入使插入点及之后的迭代器失效，删除使删除点及之后失效。结构改变后按需要重新取得迭代器。

\subsection{string：字符串}
string自动维护长度和存储空间，支持下标、拼接、比较、截取及查找。与scanf配合时先读入字符数组，再赋给string；printf用c\_str()取得字符数组形式。
% snippet:stl_string
\begin{lstlisting}
char word[101];
scanf("%100s", word);
std::string s = word;
s += "!";
printf("%s\n", s.c_str());
std::string part = s.substr(0, 2); // At most two characters.
std::string::size_type p = s.find("ab");
if (p != std::string::npos) printf("%zu\n", p);
s.insert(0, "X");
s.erase(0, 1);
s.replace(0, 1, "Y");
\end{lstlisting}
substr(pos,len)从pos截取至多len个字符；pos不能超过size。find返回起始下标，失败为npos；不要把npos转成int再判断。字符串用==判断内容相同，用<按字典序比较。

下标访问、size、empty为$O(1)$；复制和截取需要处理相应字符，长度k时为$O(k)$。中间插入、删除、替换可能移动后续字符，按字符串及替换内容长度估算。比较最坏要检查整个公共前缀；查找也可能反复比较字符，不能视为常数操作。

\subsection{pair：两个值的组合}
pair把两个值保存为first、second；默认比较先比first，相等再比second，适合坐标、距离与编号等二元数据。
% snippet:stl_pair
\begin{lstlisting}
std::pair<int, int> p = std::make_pair(3, 7);
printf("%d %d\n", p.first, p.second);
std::pair<int, int> a[3] = {{2, 4}, {1, 9}, {2, 3}};
std::sort(a, a+3); // (1,9), (2,3), (2,4).
\end{lstlisting}
访问成员为$O(1)$。比较成本取决于成员类型；int成员比较为$O(1)$。超过两个有明确含义的属性时，用结构体成员名更容易表达。

\subsection{stack：后进先出}
栈只从一端访问，最后放入的元素最先取出。push入栈，top读取栈顶，pop删除栈顶。
% snippet:stl_stack
\begin{lstlisting}
std::stack<int> st;
st.push(3); st.push(5);
if (!st.empty()) {
    int x = st.top(); // x = 5.
    st.pop();        // Leaves 3.
}
\end{lstlisting}
top、pop要求非空；pop不返回元素，要先读取再删除。默认底层为deque，以上操作以及size、empty为$O(1)$，存储n项为$O(n)$。适合保存括号、待返回的位置或最近的未完成操作。

\subsection{queue：先进先出}
队列从末尾加入、从头部取出，用于按发现顺序处理对象。
% snippet:stl_queue
\begin{lstlisting}
std::queue<int> q;
q.push(3); q.push(5);
if (!q.empty()) {
    int x = q.front(); // x = 3.
    q.pop();          // Leaves 5.
}
\end{lstlisting}
front读队首，back读队尾，二者及pop要求非空。默认底层为deque，push、pop、front、back、size、empty为$O(1)$，空间$O(n)$。

\subsection{priority\_queue：优先队列}
优先队列用堆维护当前优先级最高的元素，不保证其他元素整体有序。默认是大根堆，top为最大值；greater使它成为小根堆。
% snippet:stl_heap
\begin{lstlisting}
std::priority_queue<int> large;
std::priority_queue<int, std::vector<int>, std::greater<int> > small;
large.push(4); large.push(9);
int maximum = large.top(); // 9.
large.pop();
small.push(4); small.push(9);
int minimum = small.top(); // 4.
\end{lstlisting}
greater还需\texttt{<functional>}。push、pop为$O(\log n)$，top、size、empty为$O(1)$；top、pop要求非空。没有直接删除任意元素或按下标访问的接口。

结构体比较函数返回“a的优先级低于b”。函数指针可以作为比较器类型：
% snippet:stl_heap_struct
\begin{lstlisting}
struct Task { int priority, id; };
bool lower_priority(const Task &a, const Task &b) {
    if (a.priority != b.priority) return a.priority < b.priority;
    return a.id > b.id;
}
std::priority_queue<Task, std::vector<Task>,
                    bool (*)(const Task &, const Task &)> pq(lower_priority);
pq.push(Task{2, 3});
pq.push(Task{2, 1}); // Top has id 1.
\end{lstlisting}
这里优先级大者先出，并列时编号小者先出。比较仍须严格，不能用大于等于或小于等于。

\subsection{set：有序集合}
set按值有序存储，重复插入同一个值只保留一份。适用于动态判重、有序遍历和查找前驱后继。
% snippet:stl_set
\begin{lstlisting}
std::set<int> s;
s.insert(3); s.insert(7); s.insert(3);
std::set<int>::iterator it = s.find(3);
if (it != s.end()) s.erase(it);
it = s.lower_bound(5); // First value >= 5.
if (it != s.end()) printf("%d\n", *it); // 7.
\end{lstlisting}
insert、find、按值erase、成员lower\_bound及upper\_bound为$O(\log n)$；遍历全部元素为$O(n)$，空间$O(n)$。迭代器指向的值不能直接修改。

求严格小于x的最大值，先找第一个不小于x的元素，再退一步；若已经是begin，就不存在前驱。
\begin{lstlisting}
std::set<int>::iterator it = s.lower_bound(x);
if (it != s.begin()) { --it; printf("%d\n", *it); }
\end{lstlisting}
end不能解引用，begin不能向前退。插入不使已有迭代器失效，删除只使被删元素的迭代器失效。

\subsection{multiset：允许重复的有序集合}
multiset与set的有序操作相同，但保留重复值。按值erase(x)删除全部x；只删一个副本时，先find再按迭代器删除。
% snippet:stl_multiset
\begin{lstlisting}
std::multiset<int> s;
s.insert(4); s.insert(4); s.insert(7);
std::multiset<int>::iterator it = s.find(4);
if (it != s.end()) s.erase(it); // Deletes only one 4.
int copies = (int)s.count(4);   // 1.
s.erase(4);                    // Deletes every remaining 4.
\end{lstlisting}
插入、find、成员边界查询为$O(\log n)$。count(x)和erase(x)为$O(\log n+k)$，k是x的出现次数；按迭代器删除均摊$O(1)$，与find合用总计$O(\log n)$。

\subsection{map：有序键值映射}
map按键有序，每个键对应一个值。适用于计数、对象编号和按名称保存状态。\texttt{m[key]}在键不存在时会插入默认值；只查询是否存在时，用find。
% snippet:stl_map
\begin{lstlisting}
std::map<int, int> freq;
freq[7]++; freq[3]++; freq[7]++;
std::map<int, int>::iterator it = freq.find(5);
if (it != freq.end()) printf("%d\n", it->second);
for (it = freq.begin(); it != freq.end(); ++it)
    printf("%d %d\n", it->first, it->second);
freq.erase(3);
\end{lstlisting}
遍历输出按键升序排列，为3出现1次、7出现2次。first是键，不能直接修改；second是值，可以更新。下标、insert、find、按键erase为$O(\log n)$，完整遍历为$O(n)$，空间$O(n)$；字符串键还需计入比较字符的成本。

遍历时删除，用erase返回的下一个迭代器继续：
\begin{lstlisting}
for (std::map<int, int>::iterator it = freq.begin();
     it != freq.end(); ) {
    if (it->second == 0) it = freq.erase(it);
    else ++it;
}
\end{lstlisting}
不要删除后再递增已经失效的迭代器。

\subsection{unordered\_map：哈希键值映射}
unordered\_map按哈希值组织键值对，不保证遍历顺序，适合只需按键查询和更新的场景。下标仍会插入不存在的键。
% snippet:stl_umap
\begin{lstlisting}
std::unordered_map<int, int> freq;
freq.reserve(1000);
freq[7]++;
std::unordered_map<int, int>::iterator it = freq.find(7);
if (it != freq.end()) printf("%d\n", it->second);
freq.erase(7);
\end{lstlisting}
查找、插入和删除平均$O(1)$，最坏$O(n)$；遍历$O(n)$，空间$O(n)$。reserve预留预计元素数，减少扩容次数；重新组织哈希桶会使迭代器失效。字符串键的哈希需要读取字符，长度L时至少计入$O(L)$成本。

\subsection{unordered\_set：哈希集合}
unordered\_set只保存不同的值，适用于无需排序的判重和存在性查询。
% snippet:stl_uset
\begin{lstlisting}
std::unordered_set<int> seen;
seen.reserve(1000);
bool inserted = seen.insert(7).second; // true on first insertion.
bool exists = seen.find(7) != seen.end();
seen.erase(7);
\end{lstlisting}
insert返回的second表示是否插入了新值。查询、插入、删除平均$O(1)$，最坏$O(n)$；遍历$O(n)$，空间$O(n)$。它没有按值查找前驱、后继的lower\_bound或upper\_bound接口。
