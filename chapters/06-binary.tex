\subsection{二分}
\subsubsection{有序数组上的边界}
二分每次检查中点，排除一半候选。对非降数组$a[0..n-1]$寻找第一个不小于x的位置，维护左闭右开区间$[l,r)$；r初值为n，也表示不存在这样的元素。
% snippet:binary_array
\begin{lstlisting}
int first_ge(const int a[], int n, int x) {
    int l = 0, r = n;
    while (l < r) {
        int mid = l + (r-l) / 2;
        if (a[mid] < x) l = mid + 1;
        else r = mid;
    }
    return l;
}
\end{lstlisting}
若$a_{mid}<x$，mid及其左侧都不可能是答案；否则mid仍可能是第一个，保留它。例如$[2,2,5,7]$查2返回0，查3返回2，查8返回4。检查是否找到x时，先判断位置小于n，再访问数组。时间$O(\log n)$，额外空间$O(1)$。

\subsubsection{二分答案}
若判定check(x)随x增大由假变真，可以二分第一个可行值。初始闭区间$[L,R]$必须包含答案，且R可行。
% snippet:binary_answer
\begin{lstlisting}
int l = L, r = R;
while (l < r) {
    int mid = l + (r-l) / 2;
    if (check(mid)) r = mid;
    else l = mid + 1;
}
int answer = l;
\end{lstlisting}
可行时保留mid及其左侧，不可行时排除mid及其左侧。如果判定方向相反，就要相应调整搜索目标和边界。判定耗时T时，总时间为$O(T\log(R-L+1))$；中点公式仍要求$r-l$在类型范围内。

\subsubsection{实数二分}
实数不能用mid加1排除候选。每轮把区间长度减半；做k轮后，误差区间长度为$(R-L)/2^k$。例如求$x\ge0$的平方根，在$[0,\max(1,x)]$内寻找使平方达到x的边界。
% snippet:binary_real
\begin{lstlisting}
double sqrt_binary(double x) {
    double l = 0, r = x > 1 ? x : 1;
    for (int t = 0; t < 80; t++) {
        double mid = l + (r-l) / 2;
        if (mid * mid >= x) r = mid;
        else l = mid;
    }
    return (l+r) / 2;
}
\end{lstlisting}
本片段取$0\le x\le10^{12}$，避免平方超出double范围。固定轮数控制理论区间误差，最终精度也受浮点舍入影响。每轮常数操作，时间$O(k)$、额外空间$O(1)$。

\subsection{双指针}
双指针用两个单调移动的位置维护区间或合并两个序列。若两个指针都只前进n次，内层循环的总执行次数也是$O(n)$，而不是$O(n^2)$。
\subsubsection{滑动窗口}
对非负数组，右端加入元素不会使和减小，左端删除元素不会使和增大。求和不超过$K\ge0$的最长连续区间：每次扩展右端，超限时移动左端。
% snippet:window
\begin{lstlisting}
int left = 0, best = 0;
long long sum = 0;
for (int right = 0; right < n; right++) {
    sum += a[right];
    while (left <= right && sum > K) sum -= a[left++];
    if (right-left+1 > best) best = right-left+1;
}
\end{lstlisting}
例如$[2,1,3,1]$、K=4，前两项构成长度2的窗口；加入3后删除2，得到$[1,3]$。对每个右端，当前left是最早的可行左端，因此得到该右端的最长区间。时间$O(n)$，额外空间$O(1)$。有负数时单调性不成立，不能直接使用此规则。
\subsubsection{两个有序序列}
两个非降数组求公共元素时，小的一侧先前进；它已不可能与另一侧当前或后续更大的值相等。相等时同时前进。
% snippet:two_sequences
\begin{lstlisting}
int i = 0, j = 0, common = 0;
while (i < n && j < m) {
    if (a[i] < b[j]) i++;
    else if (a[i] > b[j]) j++;
    else { common++; i++; j++; }
}
\end{lstlisting}
重复值按多重集合交集计数：两边分别出现u、v次时贡献$\min(u,v)$。总移动次数不超过$n+m$，时间$O(n+m)$，额外空间$O(1)$。
