\subsubsection{二分依赖单调性}\ojpractice{CSP202303B}{垦田计划：第29次，2023-03，第2题；天数越大所需资源越少，找第一个可行天数，真题速看给解答}
二分的对象可以是有序数组，也可以是答案。核心是判定结果沿某个方向只变化一次。例如长度 x 能切出至少 k 段木头，那么更短的正整数长度也能做到；可行区间是前缀。先写出“真、真、假、假”的顺序，再选择搜索第一个真或最后一个真。

在闭区间 $[lo,hi]$ 搜索最后一个可行值时，取上中位数 $mid=lo+(hi-lo+1)/2$。若 mid 可行，令 lo=mid；否则 hi=mid-1。上中位数保证剩下两个元素时仍能缩小区间。每步至少排除一个候选，区间最终只剩答案。

\subsubsection{例题 切木条的最大整数长度}
\practice{P2440}{木材加工}
用“能切出的段数不少于所需数量”作判定，找最后一个可行长度。

有 n 根木条，第 i 根长度为 $a_i$。每根可切成若干长度相同的整段，剩余部分丢弃，不能拼接不同木条。至少要得到 k 段，求最大正整数段长；若连长度1都无法满足，输出0。$1\le n\le2\times10^5$，$1\le a_i\le10^9$，$1\le k\le10^{12}$。输入第一行 n、k，第二行各长度。
\begin{verbatim}
输入
4 7
20 15 10 17
输出
7
\end{verbatim}
长度7时可得 $2+2+1+2=7$ 段；长度8时只有 $2+1+1+2=6$ 段。判定函数为 $\sum_i\lfloor a_i/x\rfloor\ge k$，随 x 增大计数不增。0作为“无正整数解”的哨兵，不传入判定函数，因此不会除以0。复杂度 $O(n\log\max a_i)$，空间 $O(n)$。

\subsubsection{跳石头中的判定建模}
\practice{P2678}{跳石头}
检查两岸都被保留；可行性判断必须覆盖最后一段距离。

若目标是让相邻保留石头的最小距离尽量大，可以二分距离 x。判定时从起点向后扫描，若当前石头与上次保留位置距离小于 x，则至少需要移走其中一块。通常贪心优先移走当前中间石头，以保留更靠前的落点，为后续留下空间。计数的含义应是\textbf{达到距离要求至少需移走的数量}，不是最多能移走多少。

终点不可移走，需要单独验证末段，或者采用已证明等价的计数处理。不要只在中间石头上检查距离。二分答案的困难往往在判定函数的正确性，而不是二分循环本身。

\subsubsection{双指针如何减少重复枚举}
双指针有两种常见模型。\textbf{两个有序序列的归并：}比较两组当前位置，下标或结束时间较小的一方先移动；它不可能再和对方后续更大的位置匹配。\textbf{同一数组上的滑动窗口：}右端逐次扩大，违反条件时左端向右收缩。两者都需要证明“已丢弃的部分不可能再影响后续答案”，不能仅因为写了两个下标就称为线性算法。
两个指针不后退时，总移动至多$2n$次；内层while的各次执行累计起来是n级别，因此嵌套循环仍可能是$O(n)$。每次移动和条件检查还应是$O(1)$，若检查内部重新扫描窗口，则不再是线性。
\begin{lstlisting}
int i = 0, j = 0;
while (i < na && j < nb) {
    if (a[i].index < b[j].index) i++;
    else if (a[i].index > b[j].index) j++;
    else { /* process this matching index */ i++; j++; }
}
\end{lstlisting}
上面要求每组下标严格递增；若同一下标可以重复，必须先合并或按等值组计算贡献。稀疏向量题面已经保证严格递增，直接逐项处理即可。\ojpractice{CSP201809B}{买菜：第14次；较早结束的区间先移动}\ojpractice{CSP202006B}{稀疏向量：第19次；下标小的一项先移动，相等时累加并同时移动}
设右端点逐渐增加，若满足条件的最小左端点不会向左移动，就可保存它而不重复扫描。两个指针分别最多移动 n 次，总移动次数为 $O(n)$。有两层循环不代表一定是 $O(n^2)$，要统计指针在全程移动多少次。

\subsubsection{例题 乘积小于k的连续区间个数}
给定 n 个\textbf{正整数}，统计乘积严格小于 k 的非空连续子数组数量。$1\le n\le2\times10^5$，$1\le a_i\le10^6$，$0\le k\le10^9$。输入第一行 n、k，第二行数组。
\begin{verbatim}
输入
4 100
10 5 2 6
输出
8
\end{verbatim}
合法区间包括4个单元素、$[10,5]$、$[5,2]$、$[2,6]$、$[5,2,6]$，共8个。维护窗口乘积，每加入右端点，就在乘积过大时删除左端点。缩小后，以当前右端点结尾的合法区间有 $right-left+1$ 个。

所有数至少为1，因此缩短区间不会使乘积增大，合法左端点形成后缀。若允许负数，这个性质会失效；若允许0，除法维护也需另外处理。k不大于1时没有合法非空区间。按本题约束，乘入新元素前乘积小于 $10^9$，乘后小于 $10^{15}$，long long 足够。时间 $O(n)$，空间 $O(n)$。

\subsubsection{差值数对与重复元素}\practice{P1102}{A-B数对：排序后按相同值分组，注意重复元素贡献}
给定正整数差 c，若已排序，可对每个值 x 查找 x+c 的出现次数。使用 upper\_bound 与 lower\_bound 之差可自然处理重复。若 x 有 p 个，x+c 有 q 个，贡献是 pq，而不是1。例如 $[1,1,3,3,3]$ 且 c=2，答案是 $2\times3=6$。

当 c=0 时需先确认题目问有序数对还是无序数对，是否允许同一位置使用两次。无序且不同位置的同值组贡献为 $p(p-1)/2$，不能沿用 c>0 的计数公式。
