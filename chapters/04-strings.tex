\part{第三题：字符串解析与综合模拟}
\section{大模拟拆题方法与字符串工具}
\subsection{第三题在考什么}
第三题常把文件、角色、文档、协议或任务调度写成一套中文规则。做题的过程就是把这份说明书翻译成程序：找出要保存的对象，明确每条指令怎样改变对象，再按格式回答查询。第一题常在一个循环内完成；大模拟需要把若干个小步骤接在一起，保证它们对同一份状态有一致的理解。

例如，元素选择器可以分成“读一行文档、找父节点、拆查询、沿祖先链匹配、输出行号”五件事。每件事都能单独检查。程序长度由输入规则和对象关系决定，写到150行时，依然可以逐个函数理解。学习本篇时，先掌握七个基础构件，再用四道完整真题练习把它们组合起来。

\subsection{四步拆题法}
\subsubsection{第一步：把题面压成对象、规则、输出}
草稿纸保留三栏。对象栏写“需要记住什么”，规则栏写“什么条件触发什么动作”，输出栏写“何时输出、顺序和分隔符是什么”。以角色授权为例：对象有角色、用户、用户组；规则是找关联角色并检验三项权限；输出是每次查询一行0或1。背景故事读完后，按这三栏组织程序。

把容易混淆的条件并排写清：用户和用户组怎样区分；重复操作是否叠加；查询会不会修改状态；同一时刻多个事件先处理谁。遇到“且”“或”“任意”“所有”，在草稿上分别写成逻辑关系。角色授权就是“同一角色内三项取且，多个角色之间取或”。

\subsubsection{第二步：按子任务安排实现顺序}
先读数据范围和子任务，再估算最直接方法的成本。对象很少时，逐项扫描容易写对；对象增多后，再用编号、哈希表、倒排索引或位集合减少查找。角色授权的70\%子任务最多50个角色与关联，可以先逐条检查；满数据最多500个角色、5000次查询，下一章用位集合一次合并多个角色。

功能型子任务则按语法逐层扩展。例如化学方程式先处理元素和加号，再处理数字，最后处理括号嵌套；解压缩先完成短字面量，再读长长度，随后加入两种回溯引用。每完成一层，用对应数据确认结果。具体分值依各题子任务确定。

\subsubsection{第三步：先写函数职责，再填实现}
可以先在纸上列出下面的职责：读入对象、解析一条指令、更新状态、回答查询。每个函数约定输入、返回值和它会改变的全局状态。例如解析器约定“指针始终指向下一个未处理字符”；调度器约定“选任务前，先加入当前时刻已经到达的全部任务”。这些约定让相邻函数能够顺畅衔接。
\begin{lstlisting}
void parse_input();  // Read definitions and build lookup tables.
void apply_op();     // Parse one command and update the state.
void query();        // Read a query and print its answer.
int main() {
    parse_input();
    // Call apply_op() or query() according to the input format.
    return 0;
}
\end{lstlisting}
这是一种职责划分。静态文档只需建树和查询；解压缩则可拆为读字节、读小端整数和解码。函数名与边界应跟随题目实际操作。

\subsubsection{第四步：逐层检查输入、状态和输出}
读完一行，先检查拆出的字段；建完树，检查父编号；执行一条操作，检查被修改的对象。调试信息输出到stderr，检查完成后删除。准备一个能手算的小例子，逐轮记录“读了什么、指针在哪、状态变成什么、输出什么”。若第一次差异出现在输入阶段，就先修输入；定位到状态更新后，再检查更新条件。

建议用四组小数据起步：最小对象数；同一操作重复两次；刚好触及边界；两个规则同时生效。角色授权可分别检查直接用户、用户组、通配操作，以及两个角色各满足一半条件的情况。

\subsection{字符数组与字符串操作}
C风格字符串是以结束符\texttt{'\textbackslash0'}结尾的字符数组。长度不包括结束符，容量必须包括它。strlen求长度，strcmp比较内容，strcpy复制，头文件为\texttt{<cstring>}。
% snippet:c_string
\begin{lstlisting}
char a[20] = "cat", b[20];
int len = (int)strlen(a); // 3.
strcpy(b, a);            // Copies the final '\0' too.
b[0] = 'b';              // b is now "bat".
int relation = strcmp(a, b); // Positive: "cat" > "bat".
\end{lstlisting}
strcmp返回负数、0、正数，分别表示字典序小于、相等、大于。比较字符数组内容用strcmp；复制前检查目标容量。strlen、strcpy随长度线性增长；strcmp最坏检查完整公共前缀。循环扫描时先保存长度，避免每轮重新调用strlen。

长度上界固定、按下标扫描和使用scanf时，可以用char数组；需要拼接、截取、存进容器时，std::string写起来更直接。例如最长20字符的模板名需要21个位置存结束符，带 @ 的引用词还要增加一个位置。数组容量和scanf宽度应分别按最终读入的整个词计算。

\subsection{整行输入与字符处理}
fgets最多读取容量减1个字符，保留读到的换行，并补结束符。若一行最多有1000个正文字符，下面的容量可以容纳正文、行尾和结束符。
% snippet:line_input
\begin{lstlisting}
char line[1003];
if (fgets(line, sizeof(line), stdin) != NULL)
    line[strcspn(line, "\r\n")] = '\0';
\end{lstlisting}
strcspn返回第一个回车或换行的位置，无行尾时返回字符串长度；该位置置0，只去掉行尾，保留正文空格。先用scanf读数字，再用fgets读下一行，应先消耗数字所在行的剩余字符：
\begin{lstlisting}
int c;
while ((c = getchar()) != '\n' && c != EOF) {}
\end{lstlisting}
使用cin读数字后接getline时，使用\texttt{cin.ignore(numeric\_limits<streamsize>::max(), '\textbackslash n')}，并包含\texttt{<limits>}。若空行本身有含义，应让getline原样读入；\texttt{getline(cin >> ws, s)}会跳过行首空白及空行。

字符分类函数位于\texttt{<cctype>}。isdigit判断数字，isspace判断空白，tolower转为小写；参数先转为unsigned char，避免有符号char的负值。
% snippet:char_class
\begin{lstlisting}
int length = (int)strlen(line), digits = 0;
for (int i = 0; i < length; i++) {
    unsigned char c = (unsigned char)line[i];
    if (isdigit(c)) digits++;
    line[i] = (char)tolower(c);
}
\end{lstlisting}
扫描长度L的文本为$O(L)$。规则若指定普通空格，比较\texttt{' '}；isspace还接受制表符等空白。大小写转换应作用在规则指定的字段，例如元素选择器只转换标签，保留ID原样。

\subsection{std::string切分：空字段与连续空白}
按固定字符切分时，先决定是否保留空字段。下面的函数把\texttt{a,,b,}切成四段，其中第二段和第四段为空。空串会得到一个空字段。路径解析若忽略空段，可在处理结果时跳过它们。
% snippet:split_char
\begin{lstlisting}
std::vector<std::string> split_char(const std::string &s, char sep) {
    std::vector<std::string> result;
    std::size_t start = 0;
    for (std::size_t i = 0; i <= s.size(); i++) {
        if (i == s.size() || s[i] == sep) {
            result.push_back(s.substr(start, i - start));
            start = i + 1;
        }
    }
    return result;
}
\end{lstlisting}
按空白分词可以用\texttt{<sstream>}中的istringstream。连续空格自动合并，空行得到零个词；带引号字段则交给下一章的状态机处理。
% snippet:split_space
\begin{lstlisting}
std::vector<std::string> split_space(const std::string &s) {
    std::istringstream in(s);
    std::vector<std::string> result;
    std::string word;
    while (in >> word) result.push_back(word);
    return result;
}
\end{lstlisting}
两种切分都扫描并复制$O(L)$个字符，结果空间为$O(L)$。先区分“每个逗号都划分一个字段”和“任意多个空白分隔单词”，再选模板。

\subsection{sscanf：固定格式提取}
当字段顺序和分隔符固定时，用\texttt{<cstdio>}中的sscanf从已读入的字符串提取数值。返回值是成功赋值的字段数。下面同时使用\texttt{\%n}记录消费长度，检查末尾是否还有正文。
% snippet:scan_fields
\begin{lstlisting}
const char text[] = "192.168.1.8:8080";
int a, b, c, d, port, used = -1;
int fields = sscanf(text, "%d.%d.%d.%d:%d%n",
                    &a, &b, &c, &d, &port, &used);
bool complete = fields == 5 && used >= 0 && text[used] == '\0';
\end{lstlisting}
\texttt{\%n}本身不计入返回值。这里的complete检查结构与末尾；若题目还要求IP每段在0至255、端口在指定范围内，再逐项检查范围。\texttt{\%s}读取字符数组时应给宽度；普通\texttt{\%s}遇到空白就结束，包含空格的字段应按行读入后解析。

\subsection{字符串转整数ID：建立对象表}
名称适合输入输出，整数适合数组下标。给每个第一次出现的名称分配连续编号，就能用数组保存父节点、状态或邻接表。下面用map建立映射，编号从0开始：
% snippet:name_id
\begin{lstlisting}
std::map<std::string, int> number;
int get_id(const std::string &name) {
    std::map<std::string, int>::iterator it = number.find(name);
    if (it != number.end()) return it->second;
    int id = (int)number.size();
    number.emplace(name, id);
    return id;
}
\end{lstlisting}
定义阶段调用get\_id创建对象，查询阶段用find检查名称是否存在。\texttt{number[name]}会为新名称插入值为0的记录，因此应在需要创建或累计时使用。map查找有$O(\log U)$次键比较；unordered\_map平均查找次数为$O(1)$，两者还需计算字符串比较或哈希的成本。转成ID后，内部操作直接访问整数下标。

\subsection{strtok：原地分词的适用条件}
strtok把分隔位置改成结束符，并在内部保存下一次扫描位置。下面会把原数组改成三个独立的C字符串，连续分隔符被合并：
% snippet:tokenize_c
\begin{lstlisting}
char text[] = "a,,b c";
std::vector<std::string> words;
char *p = strtok(text, ", ");
while (p != NULL) {
    words.push_back(p);
    p = strtok(NULL, ", ");
}
\end{lstlisting}
调用对象必须是可修改的字符数组。它会丢弃空字段，且同一串分词未结束时，对另一串调用strtok会覆盖内部进度。多层分词可使用前面的切分函数，每一层独立保存扫描位置。若原文本还要用于输出或定位，先复制再分词。
