\subsection{动态规划}
动态规划把问题拆成会重复出现的子问题，保存它们的答案。状态说明“这一格代表什么”，转移说明“它由哪些更小状态得到”，初始化给出最小子问题的答案。
\subsubsection{递推与初始化}
每次走1或2阶台阶，$f_i$表示到达第i阶的方案数。最后一步来自$i-1$或$i-2$，两类方案互不相交，所以$f_i=f_{i-1}+f_{i-2}$。令$f_0=1$表示尚未走的空方案。
% snippet:stairs
\begin{lstlisting}
// n <= 90; f has n+1 slots, all results fit in long long.
f[0] = 1;
for (int i = 1; i <= n; i++) {
    f[i] = f[i-1];
    if (i >= 2) f[i] += f[i-2];
}
\end{lstlisting}
按i递增计算时，右侧状态都已得到。时间$O(n)$，空间$O(n)$。
\subsubsection{最长上升子序列}
子序列可以跳过元素，但不能改变先后顺序。令$f_i$表示以$a_i$结尾的最长严格上升子序列长度：
\[
f_i=\max\bigl(1,\ \max_{j<i,\ a_j<a_i}(f_j+1)\bigr).
\]
% snippet:lis_quadratic
\begin{lstlisting}
int answer = 0;
for (int i = 0; i < n; i++) {
    f[i] = 1;
    for (int j = 0; j < i; j++)
        if (a[j] < a[i] && f[j]+1 > f[i]) f[i] = f[j]+1;
    if (f[i] > answer) answer = f[i];
}
\end{lstlisting}
单个元素形成长度1的序列；接在较小的前驱后，长度增加1。答案取所有结尾中的最大值，时间$O(n^2)$，空间$O(n)$。

更大数据下，令tail[k]保存长度为$k+1$的上升子序列的最小末尾值。末尾越小，越容易接上新元素；tail按值严格递增。
% snippet:lis_fast
\begin{lstlisting}
int len = 0;
for (int i = 0; i < n; i++) {
    int l = 0, r = len;
    while (l < r) {
        int mid = l + (r-l) / 2;
        if (tail[mid] < a[i]) l = mid+1;
        else r = mid;
    }
    tail[l] = a[i];
    if (l == len) len++;
}
\end{lstlisting}
新值替换第一个不小于它的末尾，或在末尾追加。例如$[3,1,2]$对应tail依次为$[3]$、$[1]$、$[1,2]$。相等值只能替换，不能延长严格上升序列。len为答案；tail本身未必是一条原数组子序列。时间$O(n\log n)$，空间$O(n)$。
\subsubsection{最长公共子序列}
令$f_{i,j}$表示数组a前i项与b前j项的最长公共子序列长度。两个空前缀的答案为0：
\[
f_{i,j}=
\begin{cases}
f_{i-1,j-1}+1,&a_i=b_j,\\
\max(f_{i-1,j},f_{i,j-1}),&a_i\ne b_j.
\end{cases}
\]
相等时把这个共同元素接到较短前缀的答案后；不等时，两个末尾不能同时匹配，至少舍弃一个。
% snippet:lcs
\begin{lstlisting}
// a, b use 1-based indices; f is global and initially zero.
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
        if (a[i] == b[j]) f[i][j] = f[i-1][j-1]+1;
        else f[i][j] = std::max(f[i-1][j], f[i][j-1]);
\end{lstlisting}
答案为f[n][m]，时间和空间都是$O(nm)$。例如$[1,2,3]$与$[2,1,3]$的答案是2。
\subsubsection{滚动数组}
转移只依赖上一行时，无需保存全部历史行。LCS可以只存一行：更新前f[j]是上方，更新后的f[j-1]是左方，另用diag保存左上方。
% snippet:lcs_rolling
\begin{lstlisting}
// f[0..m] initially zero; a and b use 1-based indices.
for (int i = 1; i <= n; i++) {
    int diag = 0;
    for (int j = 1; j <= m; j++) {
        int old = f[j];
        if (a[i] == b[j]) f[j] = diag+1;
        else f[j] = std::max(f[j], f[j-1]);
        diag = old;
    }
}
\end{lstlisting}
空间降为$O(m)$，时间仍为$O(nm)$。必须先保存old，再覆盖f[j]，否则下一格取不到正确的左上方值。
