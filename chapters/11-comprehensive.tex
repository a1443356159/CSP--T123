\subsection{带引号的单行分词（教学例题）}

\textbf{题目。}一行文本由普通字符、空格和英文双引号组成。引号外的连续空格分隔单词；引号内的空格属于单词；双引号本身不输出。相邻的普通片段和引号片段属于同一个单词。空引号表示一个空单词。本题不支持转义字符。若引号不匹配，输出 ERROR。行长不超过 $10^5$。

\textbf{输入。}一整行文本，可为空。\textbf{输出。}合法时先输出单词数，随后每个单词单独一行，用方括号包住，便于看见空单词和空格。
\begin{verbatim}
输入
add "hello world" "" x
输出
4
[add]
[hello world]
[]
[x]
\end{verbatim}
\textbf{状态设计。}quoted 表示当前是否在引号内；word[0..len-1] 保存当前单词；active 表示当前单词已经开始。active 不能由 len 是否为0代替，否则空引号会丢失。遇到引号切换 quoted；遇到引号外空格时结束当前单词；其余字符追加到word并增加len。扫描结束后检查引号是否闭合，再处理最后一个单词。

\textbf{正确性。}每个字符恰好进入一种分支。引号仅改变状态，分隔空格仅结束一个已开始的单词，因此保留的字符、单词边界和空单词均符合规则。时间 $O(L)$，输出存储 $O(L)$。

\textbf{题目。}给定固定的当前目录cwd和q条路径。以斜杠开头的是绝对路径，否则相对于cwd。连续斜杠视为一个；点号目录表示当前目录；两个点号表示父目录，在根目录继续上移仍为根。普通目录名只含字母、数字、下划线。路径不含空格且非空。

\begin{verbatim}
输入
/a/b
5
../c
/x//./y/../
../../../
.
tmp/../../z
输出
/a/c
/x
/
/a/b
/a/z
\end{verbatim}

\example{授权和撤销的状态管理}
\ojpractice{CSP202206C}{角色授权：第26次认证；下面教学例题先练习较小的授权模型，原题还需处理角色关联与权限匹配}
\textbf{题目。}执行q条命令：\texttt{GRANT user resource}授予权限；\texttt{REVOKE user resource}撤销；\texttt{CHECK user resource}查询并输出YES或NO。重复授予不叠加；撤销不存在的权限不报错；未出现用户默认无权限。操作依次执行，只有CHECK输出。$1\le q\le2\times10^5$，名称为1到20个字母或数字。本题不含角色继承、通配符或优先级。
\begin{verbatim}
输入
8
CHECK alice file1
GRANT alice file1
GRANT alice file1
CHECK alice file1
REVOKE alice file1
CHECK alice file1
REVOKE bob file2
CHECK bob file2
输出
NO
YES
NO
NO
\end{verbatim}
\textbf{解答。}外层map按用户名定位，内层set保存资源。set处理重复授权。查询和撤销用find，避免无意创建空记录。所有操作依次执行，因此CHECK反映此前的状态。

设用户数U，每位用户最多持有R项权限，单次比较次数为 $O(\log U+\log R)$，还需考虑字符串比较长度。总存储不超过授予过的记录规模。权限是用户与资源的二元关系，不能只判断用户是否出现过；撤销file1不能影响file2。

\example{带括号的整数表达式}
\textbf{题目。}输入一行表达式，支持非负整数字面量、加、减、乘、括号和一元正负号。乘法优先于加减，同级二元运算从左到右；一元符号优先于乘法；只忽略普通空格。合法时输出结果，语法错误输出ERROR。不支持除法、变量和隐式乘法，例如 \texttt{2(3+4)} 非法。

行长不超过1000，括号与连续一元符号嵌套不超过100层，字面量不超过 $10^6$；保证求值过程中涉及的数值运算的中间结果绝对值不超过 $10^{12}$，本题只讨论语法错误，不要求处理溢出。
\begin{verbatim}
输入
2 * (3 + 4) - -5
输出
19
另一组输入
1 + (2 * 3
另一组输出
ERROR
\end{verbatim}
\textbf{按语法拆函数。}
\begin{verbatim}
expression = term { ('+' | '-') term }
term       = factor { '*' factor }
factor     = number | '(' expression ')' | '+' factor | '-' factor
\end{verbatim}
expression负责加减，term负责乘法，factor负责括号、数字与一元符号。共享指针p指向下一个未处理字符，每个函数返回其负责部分的值。term先完整处理乘法，从而保证优先级；循环保证减法左结合，例如 $8-3-2=3$。

解析前面一个合法表达式不代表整行合法。例如 \texttt{1 2}，解析1后还剩2，必须输出ERROR。最后检查是否读到行尾。时间 $O(L)$，递归空间与嵌套深度有关。

\example{树形文档的后代选择查询}
\ojpractice{CSP201809C}{元素选择器：第14次认证；下面先用显式父编号练习祖先链，原题还需解析缩进与选择器}
\textbf{题目。}给出按先序排列的一片有根森林，共n个节点。每行记录深度、标签和标识。根深度0，孩子比父亲深1；输入结构合法，每次深度最多增加1。标识为减号表示无标识，其余标识互不相同；标签和标识只含字母数字，长度1到20。

查询由空格分隔的选择符组成。普通选择符匹配标签，以井号开头的选择符匹配标识。\texttt{div p}表示匹配p节点，且它的某个\textbf{严格祖先}是div；\texttt{div div p}需要两个不同的div祖先按顺序出现，允许隔着其他节点。节点不能把自己当祖先。

$1\le n\le500$，$1\le q\le50$，最大深度100，每条查询1到10个选择符，查询行总长度不超过1000。第一行n、q，随后n行节点，最后q行查询。每次输出匹配数和按输入顺序排列的节点行号，编号从1开始。
\begin{verbatim}
输入
7 5
0 html -
1 body -
2 div main
3 p one
2 div side
3 p two
2 p three
p
div p
#main p
div div p
#side
输出
3 4 6 7
2 4 6
1 4
0
1 5
\end{verbatim}
\textbf{建树。}用祖先栈。读取深度d的节点时，把栈截断到长度d；栈顶就是父亲，空栈则为根，然后压入自己。读取同深度兄弟时，旧兄弟会被弹出。

\textbf{匹配。}从查询末尾开始，先检查候选节点本身，再沿父链逆序匹配剩余选择符。找到一个就继续寻找更高祖先。选择最近的匹配祖先不会损失可行解，因为它给剩余前缀保留最多的上方祖先。找齐全部选择符则接受。

候选检查最多走树高H条父边并处理K个选择符，整体为 $O(qn(H+K))$，本题规模下足够。节点7虽是p，但没有div祖先；若程序把它算入 \texttt{div p}，通常是把“之前出现的节点”误认为“当前祖先”。

\ojpractice{CSP201509C}{模板生成系统：第5次认证；下面教学题额外加入递归依赖与环检测，原题按其自身替换规则实现}
\textbf{题目。}有n个命名模板，每个由若干以空白分隔的词组成。以at符号开头的词引用另一个模板，其余词直接输出。定义全部读完后，展开指定起始模板，以单个空格连接所有普通词。从起始模板可达的引用若出现未定义名称或环，输出ERROR；不可达模板的错误不影响本次输出。

模板名互不重复，只含字母数字，长度不超过20；引用符号后必须有名称。允许空模板。$1\le n\le100$，每个定义最多100个词，每词长度最多20。保证无环情况下每个模板完整展开不超过2000个词。第一行n，随后每个定义包含名称、词数k及k个词，最后给出起始名称。
\begin{verbatim}
输入
3
title 1 world
line 3 hello @title !
all 2 @line @line
all
输出
hello world ! hello world !
另一组输入
2
a 1 @b
b 1 @a
a
另一组输出
ERROR
\end{verbatim}

\example{差值数对}
给 n 个整数和非负整数 c，求满足 $i<j$ 且 $|a_i-a_j|=c$ 的位置对数量。$1\le n\le2\times10^5$，$|a_i|\le10^9$，$0\le c\le2\times10^9$。第一行 n、c，第二行数组，输出一个整数。
\begin{verbatim}
输入
5 2
1 3 1 3 3
输出
6
\end{verbatim}
\textbf{解答。}先统计每个值的频次。c>0时，只从较小值x寻找x+c，不会重复统计同一无序数对；贡献是两组频次乘积。c=0时，频次k的组中任选两个位置，贡献 $k(k-1)/2$。答案最多为 $n(n-1)/2$，需要long long。时间 $O(n\log n)$，空间 $O(n)$。

\example{非抢占任务调度}
有一台处理器和n个任务，每个任务给定到达时刻、优先级和执行时间，输入顺序就是任务编号。处理器空闲时，在所有已经到达但尚未执行的任务中选择优先级最高者；并列时选到达更早者，再并列选编号更小者。一旦开始执行就\textbf{不能被抢占}。

一个任务完成时，必须先把恰好在该时刻到达的任务加入候选，再选择下一项。若没有已到达任务，时钟直接跳到下一次到达。输入不保证按到达时刻有序。$1\le n\le2\times10^5$，到达时刻和优先级在0到 $10^9$ 之间，执行时间在1到 $10^9$ 之间。

第一行n，随后每行依次给到达时刻、优先级、执行时间。按输入编号输出每个任务的开始和结束时刻，最后一行输出最大等待时间，等待时间为开始减到达。
\begin{verbatim}
输入
4
0 1 5
1 1 2
2 3 1
5 2 2
输出
0 5
8 10
5 6
6 8
7
\end{verbatim}
\textbf{推演。}任务1在0到5执行，中途到达的高优先级任务不能打断它。时刻5，先加入任务4；待选任务2、3、4中任务3优先级最高，所以执行顺序为1、3、4、2。任务2等到8开始，等待7。

\textbf{状态划分。}排序数组保存还未到达的任务，指针i指向下一项；优先队列保存已经到达的任务；now保存处理器可再次分配工作的时刻。每轮先补全所有到达时间不大于now的任务，再选堆顶。

\textbf{正确性。}选择前，堆恰好包含全部可选任务；比较器严格实现三级优先顺序。执行结束后更新now，不处理中途抢占，符合规则。每个任务入堆出堆各一次，排序与堆操作总时间 $O(n\log n)$，空间 $O(n)$。结束时刻可能达到 $10^{14}$ 量级，应使用long long。
